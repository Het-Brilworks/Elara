# Account Delete Page

This folder is a standalone Vite web app for account deletion.

## Run locally

1. Copy `.env.example` to `.env`.
2. Fill in the Firebase `VITE_FIREBASE_*` values.
3. Install dependencies with `npm install`.
4. Start the web app with `npm run dev`.

## Build

Run `npm run build` to generate a production web build in `dist/`.

## Scope

This page is separate from the mobile Expo app in the repository root. It uses the Firebase web SDK only and does not depend on React Native or Expo runtime code.
